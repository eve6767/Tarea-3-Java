# Tarea-3-Java

Este proyecto simula una maquina expendedora mediante una interfaz visual.

Para ejecutar el programa, solo hay que ejecutar Main.java .

Al ejecutarse se abrira una ventana con botones, informacion de los productos disponibles y la gestion del saldo la lado derecho.
El resto es una representacion grafica de la maquina expendedora.

Luego de seleccionar un producto con saldo suficiente, se mostrara un boton con el texto "Empuja" que representa sacar el producto de la zona de extraccion de la maquina.
Esto finaliza la compra de ese producto.

Incluida en este repositorio, hay una imagen de ejemplo de como se ve la ventana en ejecucion.
En caso de no ver los componentes visuales, puede ser necesario editar la direccion de la carpeta de imagenes en:

Ventana.java : Linea 59
